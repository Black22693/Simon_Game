# Simon Game 🎮

A browser-based Simon memory game completed as part of **Angela Yu's Web Development Bootcamp**.

## How to Play

1. Press any key to start.
2. Watch the color that flashes and listen to its sound.
3. Repeat the full sequence by clicking the colored buttons in order.
4. Each successful level adds another color to remember.
5. If you click the wrong color, the game ends. Press any key to restart.

## Features

- Randomly generated color sequences
- Increasing sequence length as levels progress
- Color animations and sound effects
- Level display, game-over detection, and restart functionality
